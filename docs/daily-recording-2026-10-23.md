# 日常记录升级

## 本次范围
- 同一天保留多条称重。设置“每日统计取值”为当天最后一次、第一次或最低体重；近 7/30 日均值和曲线每天只计一条，漏记日期不填零。
- 单条记录关闭写入 Apple 健康后，该次保存不会被全局开关重新开启。
- 记录 → 右上角菜单 → 日历与补录：月历显示体重和喝水标记，点选过去日期后查看或补录。正常新增仍使用当前日期时间。
- 首页 → 今日喝水 → 明细与补录：按日查看、修改、删除、补记；常用杯量支持 1–4 个快捷水量。
- 我的 → 偏好设置 → 称重与喝水提醒：默认关闭，自选时间和时段；当天已称重不再提醒，喝水支持达标暂停和跨午夜时段。
- 保存错误明确提示；保留最近有效自动备份。文件无法解码时先进入恢复界面，禁止静默覆盖原文件；显式恢复前会保留无法读取的原文件。
- JSON 备份合并包含体重和喝水，两者一起保存，失败整体回滚；覆盖恢复包含偏好与提醒设置。旧备份缺少新增字段时沿用兼容默认值。

## 验证方式
`bash tests/run.sh` 在 macOS 编译真实模型和持久化代码，在 Asia/Shanghai、America/Los_Angeles 两个时区运行回归。GitHub Actions 在回归后编译 iOS 并上传未签名 IPA。

真机验收仍需检查：同日早晚记录及健康开关、日历补录日期、喝水编辑/撤销、通知允许/拒绝/专注模式、后台切换和重启后数据、旧备份恢复、动态字体。测试不访问真实 Apple 健康或用户数据。

## 提醒限制
本地通知按未来日期预排，每次打开、修改设置或记录及日期变化时续排。总数最多 60 条；频繁喝水提醒会缩短可预排的天数。长时间不打开 App 时需重新打开续排。实际通知送达受系统授权、专注模式和系统调度影响。

## 后续范围
体脂维持原有选填字段。小组件、周报及云同步不在本次范围。
